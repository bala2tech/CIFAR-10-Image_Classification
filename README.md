
# CIFAR-10 Image Classification using PyTorch

**Deep Learning | Computer Vision | CNN | Residual Learning | Hyperparameter Optimization**

## Project Overview

This project implements and evaluates deep learning models for image classification using the CIFAR-10 dataset and PyTorch.

The objective is to build a baseline Convolutional Neural Network (CNN), improve model performance using residual learning and hyperparameter tuning, and evaluate training utilities such as Early Stopping and Gradient Clipping.

## Dataset

CIFAR-10 contains 60,000 color images across 10 classes.

- Training samples: 45,000
- Validation samples: 5,000
- Testing samples: 10,000
- Image dimensions: 32 × 32 × 3
- Number of classes: 10

## Models Implemented

1. **Baseline CNN** – Custom convolutional neural network with Batch Normalization and Dropout.
2. **Residual CNN** – CNN architecture incorporating custom residual blocks.
3. **Hyperparameter-Tuned CNN** – Experiments with learning rate, batch size, optimizer and dropout rate.
4. **Callback-Enabled CNN** – Training utility incorporating Early Stopping and Gradient Clipping.
